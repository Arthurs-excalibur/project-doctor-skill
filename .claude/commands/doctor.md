Read the project-doctor skill from skills/project-doctor/SKILL.md, then run Project Doctor using the AUDIT operating mode.

Inspect the entire project. Do not modify any files. Produce a prioritized report covering:
- Project health baseline (build, tests, lint, type-check).
- Source code and architecture findings.
- Dependency and tooling findings.
- Asset and frontend findings.
- Backend and integration findings.
- Database and persistence findings.
- Configuration and delivery findings.
- Deployment architecture recommendation with verified free-tier options.

Classify every finding with evidence and a confidence level: CONFIRMED UNUSED, LIKELY REDUNDANT, NEEDS INVESTIGATION, REQUIRED, BROKEN, or IMPROVEMENT.
