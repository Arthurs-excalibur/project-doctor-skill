Read the project-doctor skill from skills/project-doctor/SKILL.md, then run Project Doctor using the CLEAN & REPAIR operating mode.

1. Establish the project health baseline first (build, tests, lint, type-check).
2. Audit the entire project across all layers.
3. Classify findings with evidence.
4. Plan safe changes, starting with low-risk cleanup.
5. Execute changes incrementally. Verify after each change.
6. Repair any regressions introduced by your changes.
7. Run final verification and produce a report comparing results against the baseline.
